### How I approach engineering

- **Reliability over heroics** — systems should be designed so engineers aren't constantly rescuing them
- **Automation over repetition** — recurring manual work is a tooling opportunity
- **Visibility over guesswork** — metrics, logs, and traces should make system state obvious
- **Business context matters** — how a system is used is as important as how it's built
- **Build things people use** — the work should end with someone doing their job faster or better
